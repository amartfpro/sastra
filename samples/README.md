# Archivos de prueba

Archivos reales que sirven de referencia y para comprobar que cada versión funciona con material de verdad.

| Carpeta | Qué va aquí | Para qué entrega |
| --- | --- | --- |
| `fichas/` | 3 fichas técnicas actuales (básica, media y compleja), en PDF, Excel o Illustrator | 1.1 – 1.4 |
| `graficos/` | Archivos PSD y AI de estampados y bordados, incluidos casos difíciles (CMYK, 16 bits, PSB, AI sin compatibilidad PDF) | 1.2 |
| `patrones/` | Patrones en DXF, PDF o de Seamly2D/Valentina | 2 |

El repositorio es público: no subas aquí nada confidencial de clientes o marcas. Si un archivo no se puede
compartir, guárdalo fuera del repositorio y avisa de dónde está.
